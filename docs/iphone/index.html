아이폰 공식 연동 안내

아이폰 무선 카플레이 · 1초 자동 핫스팟

앱스토어 설치 없이 아이폰 순정 기능만으로 시동 시 자동 연결됩니다.

1. 무선 카플레이 연결

  1. 아이폰 설정 → 블루투스와 와이파이를 모두 켜 주세요.
  2. 블루투스 목록에서 엘리포엠 안드로이드오토를 눌러 연결합니다.
  3. 화면에 뜨는 안내창에서 카플레이 사용을 누르면 다음 시동부터 자동 실행됩니다.

2. 시동 켤 때 1초 자동 핫스팟 켜기

  1. 차량 올인원의 자동 핫스팟 → 설정에서 핫스팟 이름(iPhone)과 비밀번호를 1회 저장합니다.
  2. 아래 버튼을 눌러 아이폰 기본 단축어 앱을 엽니다.
  3. 하단 자동화 → [+] → 블루투스에서 기기 엘리포엠 안드로이드오토, 연결됨, 즉시 실행을 선택합니다.
  4. 동작에서 개인용 핫스팟 설정 → 켜기를 추가하면 시동 켤 때마다 자동으로 연결됩니다.

3. 차량 전용 리모컨 웹앱 열기

차량이 아이폰 개인용 핫스팟에 연결된 상태에서 아래 버튼을 누르거나 사파리에서 차량 주소를 열고 홈 화면에 추가를 누르면 바탕화면 앱으로 작동합니다.
