아이폰 공식 연동 안내

아이폰 무선 카플레이 · 자동 핫스팟

앱 설치나 복잡한 숫자 주소 입력 없이 시동만 켜면 바로 연결됩니다.

1. 무선 카플레이 연결

  1. 아이폰 설정 → 시리(Siri)가 켜져 있어야 카플레이 화면이 열립니다.
  2. 아이폰 설정 → 블루투스와 와이파이를 모두 켜 주세요.
  3. 블루투스 목록에서 엘리포엠 안드로이드오토를 눌러 연결합니다.
  4. 화면에 뜨는 안내창에서 카플레이 사용을 누르면 다음 시동부터 자동 실행됩니다.

2. 자동 핫스팟 (단축어 없어도 바로 연결)

  1. 아이폰 설정 → 개인용 핫스팟 → 다른 사람의 연결 허용만 켜 두면, 단축어를 만들지 않아도 블루투스 연결 즉시 인터넷이 자동 연결됩니다.
  2. 더 빠른 초고속 와이파이 핫스팟 자동 전환까지 원하시면 차량에서 핫스팟 비밀번호를 1회 저장한 뒤 아래 버튼으로 단축어 → 자동화 → 블루투스(엘리포엠 안드로이드오토 · 연결됨 · 즉시 실행) → 개인용 핫스팟 켜기를 추가해 주세요.

3. 숫자 입력 없는 차량 리모컨 열기

차량과 같은 핫스팟이나 와이파이에 있을 때 아래 버튼을 누르거나 사파리에서 eliphoem.local:8580 을 열고 홈 화면에 추가를 누르면 바탕화면 앱으로 작동합니다.
