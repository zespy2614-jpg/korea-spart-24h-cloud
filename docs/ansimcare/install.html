안심케어

안심케어 앱 받기

휴대폰에 앱을 설치하면 본체를 찾아 연결하고, 카메라 영상과 알림을 볼 수 있어요.

안드로이드 휴대폰용 앱

버전 3.3.1

안심케어 앱 받기
받기를 누른 뒤 이렇게 해 주세요
  1. 안내창이 나오면 [다운로드]를 누르세요. ‘폰에 손상을 줄 수 있습니다’라고 나와도 안심케어 앱이에요.
  2. 다 받으면 화면 아래 [파일 열기]를 바로 누르세요. 3초쯤 뒤에 사라져요. 놓쳤다면 ‘내 파일’ 앱 → [설치 파일]에서 안심케어 파일을 누르세요.
  3. [설치]를 누르세요. ‘알 수 없는 앱’ 안내가 나오면 [설정]에서 허용을 켜고 돌아오세요. ‘Play 프로텍트’ 안내가 나오면 [앱 검사]를 누르고 안내대로 마치세요.
설치한 앱 열기

설치한 다음에는

  1. 본체 전원을 켜고, 카메라가 본체에 연결돼 있는지 확인하세요.
  2. 앱에서 [기기 연결]을 누르고 주변 기기 권한을 허용하세요.
  3. 찾은 본체를 고른 뒤 본체의 연결 버튼을 한 번 누르면 연결돼요. 새 본체는 고르기만 하면 돼요.

영상은 휴대폰과 본체가 같은 와이파이에 있을 때 볼 수 있어요. 아이폰용 앱은 아직 없어요.
