스마트폰 설치 안내 (10초 완료)

  • 1단계.위 파란색 엘리포엠 앱 다운로드 (v6.2) 버튼을 누른 뒤 상단 알림창에서 다운로드된 파일을 누릅니다.

  • 3단계.Play 프로텍트 안내 창이 뜨면 세부정보 더보기 → 무시하고 설치를 누르면 즉시 설치됩니다.
  • 4단계.앱 실행 후 자동 제어 권한 활성화를 켜두시면 차에 탈 때마다 자동으로 핫스팟이 켜집니다.
