스마트폰 10초 설치 방법

  • 1단계.위 파란색 스마트폰용 앱 다운로드 (v6.21) 버튼을 누른 뒤 상단 알림창에서 다운로드된 파일을 누릅니다.
  • 2단계.보안 안내 창이 나오면 설정 → 이 출처 허용을 켜고 설치를 누릅니다.
  • 3단계.Play 프로텍트 안내 창이 뜨면 세부정보 더보기 → 무시하고 설치를 누르면 즉시 설치됩니다.
  • 4단계.앱 실행 후 설정 → 자동 연결 허용 → 설정 시작을 눌러 안내대로 허용하시면 차에 탈 때마다 자동으로 핫스팟이 켜집니다.
